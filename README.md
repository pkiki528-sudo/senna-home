# senna.dev — home

Rumah ekosistem digital **senna.dev**: Kiki Pratama, SennMarket, dan SennPayy.

## Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- Framer Motion

## Dev

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).
